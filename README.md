# EventLantern marketing website

The public marketing site for [EventLantern](https://eventlantern.com), the event management platform formerly called EventBound. It is a static site built with Astro and Tailwind, published to GitHub Pages.

- **Live site:** https://eventlantern.com
- **Product app (sign in, signup, terms, privacy):** https://app.eventlantern.com
- **Stack:** [Astro 5](https://astro.build) (static output) and [Tailwind CSS 4](https://tailwindcss.com), TypeScript for config and data
- **Hosting:** GitHub Pages, deployed by GitHub Actions on every push to `main`

## Run it locally

You need Node.js 20 or newer (CI uses Node 22).

```bash
npm install
npm run dev
```

The dev server runs at http://localhost:4321.

| Command | What it does |
|---|---|
| `npm run dev` | Start the dev server with hot reload |
| `npm run build` | Build the static site into `dist/` |
| `npm run preview` | Serve the built `dist/` locally |

## Where things live

```
src/
  config.ts          Site and app URLs, contact email, social links, Formspree form ID
  data/
    pricing.ts       Plans and the plan comparison matrix
    solutions.ts     Content for the /solutions/* landing pages
  pages/             One file per route (index, why, pricing, integrations, security,
                     about, contact, eventbound, 404, solutions/)
  components/        Nav, Footer, PageHero, CtaBand, FaqAccordion, Flame, Embers, ...
  layouts/
    BaseLayout.astro Page shell: SEO tags, structured data, analytics, scroll reveal
  lib/logos.ts       Brand marks for the integration logos
  styles/global.css  Design tokens (colors, type) and shared styles and animations
public/              Logos, favicons, web manifest, robots.txt, llms.txt, CNAME
.github/workflows/   deploy.yml (build and publish to GitHub Pages)
```

### Common edits

- **Change a URL, the contact email, or a social link:** edit `src/config.ts`. Everything reads from there, so nothing is hard-coded across pages.
- **Change prices or plan limits:** edit `src/data/pricing.ts`. The home page and `/pricing` use it.
- **Add or edit a solutions page:** edit `src/data/solutions.ts`. Each entry becomes a page at `/solutions/<slug>` through `src/pages/solutions/[slug].astro`. Keep claims in line with `pricing.ts` and the home page, and do not describe features the product does not ship.
- **Change colors or fonts:** edit the `@theme` block at the top of `src/styles/global.css`.

## Brand

The visual identity is the "Wick" logo package. The master files are kept outside this repo, and the web-ready copies are in `public/`.

| Token | Value | Use |
|---|---|---|
| Ink (navy) | `#111B3A` | Text, dark sections, hero backgrounds |
| Brass | `#B98222` | The flame and small accents |
| Ivory | `#F7F3E8` | Page background |

- **Type:** Sora for headings and body, IBM Plex Mono for labels and prices. Both load from Google Fonts.
- **Brass is an accent, not a text color on ivory.** Use `text-brass-text` (a darker tone) for small text on light backgrounds, and `text-brass-glow` on navy.
- **Motion:** heroes, the headline reveal, the marquee and scroll reveals all respect `prefers-reduced-motion`.
- **Integration logos:** the third-party marks come from `@iconify-json/logos` (CC0) and keep their own brand colors. The names and logos are trademarks of their owners and appear only to show compatibility.

## Deploying

Pushing to `main` runs `.github/workflows/deploy.yml`, which builds the site and publishes `dist/` to GitHub Pages. There is nothing to do by hand.

One-time setup (already done for this repo):

1. **Settings > Pages > Source:** set to **GitHub Actions**.
2. **Custom domain:** `eventlantern.com`, with **Enforce HTTPS** on. The `public/CNAME` file records the domain.
3. **DNS at the registrar:** four `A` records for the apex (`185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`) and a `CNAME` for `www` pointing to `stephensonck.github.io`.

## Services and integrations

- **Contact form:** posts to [Formspree](https://formspree.io) using the form ID in `src/config.ts`. Where the notification emails go is set in the Formspree dashboard, not in this repo.
- **Analytics:** [Cloudflare Web Analytics](https://www.cloudflare.com/web-analytics/), added in `BaseLayout.astro`. It is cookieless.
- **Signup redirect:** `/signup` is a static redirect to the app, set by `redirects` in `astro.config.mjs`.
- **Search and AI discovery:** the sitemap is generated by `@astrojs/sitemap`. Structured data (Organization, WebSite, breadcrumbs, FAQ, software offers) is emitted from the layout and pages. `public/llms.txt` is a plain-text summary for LLM crawlers; keep it in step with the real plans and features.

## The old EventBound domain

`eventbound.tech` is not served from this repo. It redirects every path to the same path on `eventlantern.com`, and `/signup` to the app. That redirect is handled by a separate host outside this repo, which has to stay up for the redirect to keep working. `app.eventbound.tech` is not redirected.

## Troubleshooting

- **`EBUSY: resource busy or locked` during `npm run build` on Windows.** This happens when the project sits in a synced folder such as Dropbox and the sync client holds `dist/` or `.astro/`. The pages still generate. To build cleanly, output somewhere outside the synced folder:

  ```bash
  npx astro build --outDir "$TEMP/eventlantern-dist"
  ```

  CI is not affected.
- **Contact form shows "Something went wrong".** Check that `FORMSPREE_ID` in `src/config.ts` matches an active form in your Formspree account.
